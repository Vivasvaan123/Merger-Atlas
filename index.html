About this prototype

All exported fitted rows are available. Only the exported preview test objects have images here. No model runs in the browser. PCA uses processed morphology measurements, not a direct image embedding. Stored catalog mass/SFR units and log conventions are not independently verified. Selection is retained across filters; previews use fixed DS9-square stretch and pre-rendered overlays. This is not a public-release scientific validation.
